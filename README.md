# 📈 Higher or Lower — Instagram Followers

A simple command-line game built with Python where you guess which of two Instagram accounts has more followers.

## 📖 About

The game randomly selects two accounts from a predefined dataset and displays their names, descriptions, and countries. Your job is to decide which account has more followers by choosing **A** or **B**.

If your answer is correct, your score increases and the game continues. The account from position B becomes the next comparison, making the game progressively harder.

The project was built to practice Python fundamentals such as functions, lists, dictionaries, loops, conditionals, random selection, and score tracking.

## 🎮 How to Play

1. The game displays two Instagram accounts.
2. Compare the two accounts.
3. Enter `A` if you think Account A has more followers.
4. Enter `B` if you think Account B has more followers.
5. If you're correct, your score increases.
6. Keep playing until you make an incorrect guess.
